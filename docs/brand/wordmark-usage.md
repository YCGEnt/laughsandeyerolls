# Wordmark Usage

The Laughs & Eye Rolls wordmark must use the supplied SVG artwork rather than recreated typography.

## Assets

- `Espresso-wordmark-primary.svg` is used for hero sections.
- `Espresso-wordmark-compact.svg` is used for navigation, footer, mobile headers, and constrained spaces.

## Repository Paths

The application expects the supplied files at:

- `public/brand/Espresso-wordmark-primary.svg`
- `public/brand/Espresso-wordmark-compact.svg`

If these files are missing, add the original supplied SVG assets at those exact paths. Do not trace, redraw, or approximate the wordmark with text.
